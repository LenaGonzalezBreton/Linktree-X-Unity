# 🌐 Proof Of Concept — Léna Gonzalez-Breton

Un POC réalisé avec **React (Vite)**, servant de vitrine rapide pour ma candidature chez Kolizeo.
Il inclut un **menu type Linktree** avec mes liens principaux (GitHub, CV)
et une **intégration d’un build Unity WebGL** directement dans la page.

---

## 🚀 Aperçu

💻 Technologies :

* **React + Vite**
* **HTML / CSS natif**
* **Unity WebGL (build intégré)**

---

## 🧱 Structure

```bash
src/
  components/
    LinkButton.jsx     # Boutons du menu
    UnityEmbed.jsx      # Iframe contenant le build Unity WebGL
  App.jsx               # Page principale
public/
  cv.pdf                # CV visible via le bouton “Voir mon CV”
  unity-build/          # Build Unity exporté en WebGL
```

---

## ⚙️ Installation & Lancement

```bash
# Cloner le repo
git clone https://github.com/lenagonzalezbreton/Lintree-X-Unity.git
cd Lintree-X-Unity

# Installer les dépendances
npm install

# Lancer en local
npm run dev
```
